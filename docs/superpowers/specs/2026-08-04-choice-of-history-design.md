# 《择决千秋》设计文档

> 皇帝模拟 · 月度抉择 · 历史分支
> 创建日期：2026-08-04

## 一、项目概述

### 1.1 游戏概念
玩家选择扮演中国历史上任意一位皇帝（夏至清全覆盖），以每月一次的「五选一」抉择推进游戏。选择需符合时代特点、彼此差异显著、无一眼可辨的好坏。前序选择对后续产生关键或累积影响。游戏整体进程以二十四史、资治通鉴为历史骨架，但玩家决策可改变历史走向。

### 1.2 核心特色
- **历史为骨，选择为肉**：历史事件作为骨架触发，玩家选择可分支
- **六维数值，寿命自决**：不固定历史寿命，由累积选择决定驾崩时机
- **科技穿越**：科技值可超越时代，体现「穿越者」能力，但触发保守派阻力
- **史官点评**：每次选择后以史书体例点评，强化史籍沉浸感
- **AI驱动，提示词详尽**：针对不同水平AI设计完整容错的中文提示词

### 1.3 技术约束
- 单 `index.html` 文件，内含全部 HTML + CSS + 原生 JS
- 仅外部依赖：Google Fonts（`Ma Shan Zheng` 书法 + `Noto Serif SC` 宋体）
- 无构建步骤，无 npm 依赖，双击即可运行
- 通过 OpenAI 兼容 API 实时生成事件与后果

## 三、核心数值系统

### 3.1 六项数值（0-100）

| 数值 | 含义 | 初始来源 | 崩盘后果（≤10触发危机，=0游戏结束或重创） |
|------|------|----------|------------------------------------------|
| 国库 | 财政储备 | 依皇帝即位时国力 | ≤10：叛乱/加税恶性循环；=0：国破 |
| 民心 | 百姓拥戴 | 依即位时民情 | ≤10：民变起义；=0：被推翻 |
| 军事 | 军力强弱 | 依即位时军力 | ≤10：外敌入侵/军阀割据 |
| 朝政 | 朝臣支持/政局稳定 | 依即位时党争 | ≤10：宫廷政变/权臣篡位 |
| 健康 | 皇帝身体 | 依即位时年龄与健康 | =0：**驾崩，游戏结束** |
| 科技 | 时代科技+穿越创新 | 依该时代历史科技水平 | 见 3.3 科技机制 |

### 3.2 寿命机制
- **不固定历史寿命**：玩家寿命由累积选择决定
- 每月健康变化：好选择 +1~3，坏选择 -2~5，危机事件 -10~20
- 长期数值高位（平均>60）：每月健康 +1 延寿
- 长期数值低位（平均<30）：每月健康 -2 减寿
- 健康=0 驾崩，进入结算

### 3.3 科技机制（穿越者能力）
- **初始值**：依该皇帝时代历史科技水平（如秦汉约25、唐宋约45、明清约55）
- **提升途径**：玩家可选择「超越时代」的决策（引入新式农具、改进冶炼、兴办学校、鼓励发明等），科技+3~8
- **解锁加成**：科技每达阈值（30/50/70）解锁新选项类型，并对国库/军事有加成
- **阻力机制**：科技远超时代基线（超出+20）时，触发「保守派阻力」事件——朝政、民心下降，朝臣上疏反对「奇技淫巧」
- **历史锚定**：科技值不会自动超越时代，仅玩家主动选择方可突破

### 3.4 数值变化规则
- 单次选择数值变化硬限制：**±15**（防止AI失控）
- 危机事件可突破限制但单项最多 ±25
- 数值低于10时触发对应危机事件（AI生成或预设）
- 数值长期（连续6月）极低会加速崩盘

## 四、皇帝选择系统

### 4.1 朝代列表（18个）
夏 → 商 → 周（西周/东周/春秋/战国）→ 秦 → 汉（西汉/东汉）→ 新 → 三国（魏/蜀/吴）→ 晋（西晋/东晋）→ 南北朝 → 隋 → 唐 → 五代十国 → 宋（北宋/南宋）→ 辽 → 金 → 元 → 明 → 清

### 4.2 皇帝列表
每个朝代展开该朝代所有皇帝，显示：
- 姓名 + 庙号/谥号（如「刘彻 · 汉武帝」）
- 在位年份（如「前141-前87」）
- 一句评价（如「雄才大略，开疆拓土」）

### 4.3 事件库覆盖策略
**所有皇帝均内置事件库**，分两级深度：

**甲类（详细事件库）** — 约30-50位明君/昏君/末代之主：
- 秦始皇、汉高祖、汉武帝、汉光武帝、隋文帝、隋炀帝、唐太宗、唐玄宗、宋太祖、宋徽宗、宋高宗、元世祖、明太祖、明成祖、明崇祯、清康熙、清雍正、清乾隆 等
- 每位10-20个关键历史事件，按年份触发
- 5选项含历史实际决策 + 4个符合时代的分支

**乙类（精简事件库）** — 其余皇帝：
- 每位至少5-8个关键事件（登基/重大战事/改革/灾异/外交/驾崩等里程碑）
- 事件均基于《二十四史》《资治通鉴》等正史记载，开发阶段广泛查阅正史补足，不以"AI生成"作为事件稀缺的退路
- 日常月由AI在正史事件之间生成衔接性政务，但核心历史节点必须有预设事件锚定

### 4.4 皇帝数据结构
```javascript
{
  id: "han_wudi",
  dynasty: "汉",
  name: "刘彻",
  templeName: "汉武帝",
  reignStart: -141,  // 前141年
  reignEnd: -87,
  evaluation: "雄才大略，开疆拓土",
  background: "景帝之子，七岁立为太子...",  // 开局背景介绍
  initStats: { treasury: 70, people: 65, military: 60, court: 75, health: 80, tech: 28 },
  eraContext: "汉初休养生息后国力充实，匈奴为患...",  // 时代背景（供AI）
  events: [ /* 事件库 */ ],
  tier: "A"  // A=甲类详细, B=乙类精简
}
```

## 五、每月五选一机制

### 5.1 事件触发逻辑
每月进入时：
1. 检查当前年份是否命中预设历史事件 → 触发历史事件
2. 否则 → 调用AI生成日常事件
3. 检查数值危机（任一≤10）→ 插入危机事件（优先级最高）

### 5.2 历史事件结构
```javascript
{
  year: -133,
  month: null,  // null=任意月触发
  title: "马邑之谋",
  description: "王恢献策，欲于马邑伏击匈奴...",
  historicalChoice: 0,  // 历史实际选择索引
  choices: [
    "采纳王恢之策，设伏马邑",        // 历史实际
    "遣使和亲，暂缓边衅",             // 保守
    "联合西域，断匈奴右臂",           // 远交
    "主动出击，直捣龙城",             // 进取
    "纳粟拜爵，充实军备再图后举"      // 内政
  ],
  // 后果由AI根据选择动态生成，但历史选择有预设倾向
  historicalOutcome: "汉军无功而返，汉匈决裂，开启长期战争"
}
```

### 5.3 五选项差异化硬性要求（写入提示词）
1. 5个选项**倾向显著不同**：覆盖 进取/保守/革新/怀柔/铁腕 等不同维度
2. **不能一眼分辨好坏**：每个选项有得有失，短期收益与长期风险需权衡
3. **符合时代特点**：不可穿越（如宋末无火器外交、汉初无科举）
4. **相互排斥**：选一不可兼得其他
5. **后果非线性**：相同选择在不同数值状态下后果不同

## 六、API配置与调用

### 6.1 配置界面
游戏内「设置」页提供：
- API 地址（默认 `https://api.openai.com/v1`）
- API Key（密码输入框）
- 模型名（默认 `gpt-4o-mini`）
- 温度（默认 0.8，滑块 0-1）
- 「测试连接」按钮

配置存储于 `localStorage`。

### 6.2 调用流程
1. 构建系统提示词（皇帝背景+时代约束+格式规范）
2. 构建用户提示词（当前状态+历史上下文+生成任务）
3. POST `/chat/completions`，`response_format: { type: "json_object" }`
4. 解析JSON，校验数值变化范围
5. 失败重试（最多2次），降级到预设后备事件

### 6.3 容错设计
| 异常 | 处理 |
|------|------|
| JSON解析失败 | 重试2次，仍失败用后备事件池 |
| 超时（30秒） | 提示玩家重试或跳过本月 |
| 数值变化超限 | 硬截断到 ±15 |
| 内容穿越/违规 | 重试，提示词已约束 |
| API未配置 | 引导至设置页 |

## 九、游戏循环

### 9.1 主循环
```
启动 → 主菜单（新游戏/读档/设置/关于）
  ↓
新游戏 → 朝代选择 → 皇帝选择 → 显示皇帝背景介绍
  ↓
游戏主界面（月循环）：
  1. 渲染年号·月份 + 6项数值
  2. 判定事件来源（历史/日常/危机）
  3. 显示事件描述 + 5选项
  4. 玩家选择
  5. 调用AI生成后果
  6. 显示后果叙述 + 史官点评 + 数值变化动画
  7. 更新数值，自动存档
  8. 推进下月
  ↓
健康=0 → 驾崩结算
  ↓
结算画面：在位年数 / 后世史官总评 / 关键决策回顾 / 数值曲线
  ↓
返回主菜单
```

### 9.2 结算评价
- 在位年数
- 六项数值最终值与均值
- 后世史官总评（依均值定档：明君/庸君/昏君/亡国之主）
- 关键决策回顾（选取5-10个重大抉择）
- 与历史实际对比（若甲类皇帝）
