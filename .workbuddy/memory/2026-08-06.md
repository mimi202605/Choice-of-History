# 2026-08-06 工作记录

## 健康度数值平衡修复（难度下调 + 异常暴跌 bug 修正）
- 现象：用户反馈游戏难度偏高，且健康度存在"无明确触发原因的异常快速下降"。
- 排查手段：新增 `tools/sim_health.js` 无头轨迹模拟器，用真实引擎离线/速通模式跑"理性玩家"与"随机玩家"，逐月区分「事件结算」与「被动衰减(nextMonth)」两类健康变化。
- 根因定位：
  1. **超期悬崖**：`nextMonth` 中 `year > reignEnd+5 → 健康 -3/月`，叠加年迈惩罚后单月可达 `-5~-6` 且无回复机制，进入超期即注定 15~20 月内驾崩——即"无触发原因的异常暴跌"。
  2. **年龄语义 bug**：`ageYears = year - reignStart` 算的是"在位年数"而非皇帝真实年龄，把"年迈体衰"错挂到在位时长上。
  3. **危机后果幅度过大（AI 模式）**：`applyOutcome` 危机 `limit = 25+8p`，中段可单次扣健康近 30 点。
- 修复（均在 `index.html`）：
  - 危机 `limit`：`Math.round(25+8*p):15` → `Math.round(12+5*p):10`（降危机杀伤）。
  - `STANCE_PROFILES`：铁腕 `health:-2 → -1`；进取去掉 `health:-1`（军事冒险不损龙体）。
  - 重写 `nextMonth` 寿命/超期块：
    - 恢复门槛 `avg>60 → avg>=55`（更易回血，降难度）；
    - `avg<30` 被动 `-2 → -1`（缓和低位死亡螺旋）；
    - 真实年龄 `ageYears = (emperor.ascendAge||25) + (year-reignStart)`，晚年缓降（>70 岁 -1，>80 岁再 -1）；
    - 超期改为温和递减：每超约 3 年 -1，封顶 -2（取消 reignEnd+5 后骤降 -3 悬崖）；
    - **被动损耗单月净损耗封顶 -2**，杜绝任何叠加导致的悬崖式暴跌。
- 验证：
  - `tools/sim_health.js` 显示正常在位期 0% 驾崩；长在位皇帝（汉武/康熙/乾隆 54~61 年）正常期最低 30~35（合理"龙体渐衰"），超期温和递减无悬崖。
  - `tools/validate_headless.js` 回归：**42/42 全绿，exit 0**，零回归。
- 备注：`tools/sim_health.js` 作为可复用的平衡/回归诊断工具保留。

## 选项属性平衡修复（纯降无升 → 每个选项至少一项增益）
- 现象：部分选项被选择后所有属性都下降/不变，没有任何提升，即"全降无升"的纯惩罚性/无效选项，在游戏设计中不合理。
- 根因分析：
  1. **AI 后果全负数**：`applyOutcome` 直接采纳模型返回的 `statChanges`，若模型返回全 ≤0，则无任何增益（仅 clamp 幅度，不限符号）。
  2. **后备后果"权衡"无 profile**：`fallbackOutcome` 中 `hintFromText` 匹配失败时落到 `sk="权衡"`，但 `STANCE_PROFILES` 无此项 → 所有属性变动为 0（无效选项）。
  3. **后备后果 limit 未同步**：`fallbackOutcome` 中危机 limit 仍为 25:15，远超 AI 模式的 12+5p:10（上次修复仅改了 applyOutcome）。
- 修复（均在 `index.html`）：
  - `STANCE_PROFILES` 新增 `"权衡":{treasury:1,people:1,court:1}`——兜底选项提供 3 项小额正面增益。
  - `applyOutcome` 增加安全网：若 AI 返回的所有 `statChanges` ≤0，自动给数值最低的非健康属性补 +2，杜绝纯惩罚性选项。
  - `fallbackOutcome` 增加相同安全网；并将 limit 同步为 `12:10`（与 applyOutcome 一致）。
- 验证：
  - `tools/validate_headless.js` 回归：**42/42 全绿，exit 0**。
  - 存档输出中"权衡·审势"选项已正确获得 `treasury:1, people:1, court:1` 三项正面增益。
