## 修复：游戏卡在「载入史册」无法进入（TDZ 回归）
- 现象：发布到 https://mimi202605.github.io/Choice-of-History/ 后，进入即卡在「载入史册…正在加载皇帝数据库」，loader 永不消失。
- 根因：上轮加密改造把加密常量块（`const BUILTIN_DEFAULT_MODEL` 等）放在 `function loadSettings(){` 之前、但位于顶层 `let settings=loadSettings();`（约 964 行）**之后**。脚本顶层一执行到 `loadSettings()` 就引用尚未初始化的 `BUILTIN_DEFAULT_MODEL`（const 暂时性死区 TDZ）→ 抛 `ReferenceError: Cannot access 'BUILTIN_DEFAULT_MODEL' before initialization` → 顶层脚本中断 → 启动引导 IIFE 从未执行 → loader 卡死。
- 修复：将整个加密常量块（`BUILTIN_CRED_CIPHER`/`BUILTIN_DEFAULT_MODEL`/`COH_CIPHER`/`resolveCreds`/`hasCreds` 等）整体移动到 `let settings=loadSettings();` **之前**，并删除原位置的重复定义。
- 验证：用 Node + 模拟 DOM/localStorage/fetch 实跑本地 index.html（tools/sim_local.js，已删）→ 顶层不再抛错、loader 成功隐藏（show=false）、resolveCreds 正确解出明文凭据；整文件语法 OK、无重复 const 定义、常量顺序正确。
